# 测量方法

## 时间：先确认“真实帧”

平台转码常把原片补帧到 60 fps（重复帧），或混帧（相邻两帧叠加）。做法：

1. 逐帧灰度差分（`crashlab/forensics.py`）。差值低于“邻域真实帧差值 90 分位 × 25%”判为重复。
2. 输出每个真实帧被重复显示几次的直方图；时刻不确定度 = 0.5 × 停留时长（95 分位）。
3. 画面里有监控时钟时，用“秒跳”校准时间轴（每次秒跳之间的真实帧数应恒定）。

## 运动相机（行车记录仪）

平直路面、光轴近似水平时，地面上第 y 行的距离：

    Z(y) = C / (y − y_h),   C = f · h

- y_h：地平线（车道线延长线交点所在行）。不确定度 ±10 px 量级，进蒙特卡洛。
- **速度**：虚线周期 P（线段 + 间隔）是绝对尺度。同一行被相邻两段虚线扫过的时间差 T → v = P / T。
  常见规格：3 m + 9 m（P=12，占空比 25%）；国标高速 6 m + 9 m（P=15，占空比 40%）；城市道路 2+4、4+6 等。
  用实测占空比（同一行上“底边→顶边”的越线时长 ÷ T）选主假设，**两种结果都要报**。
- **C = f·h**：同一段虚线顶边先后越过 r1、r2 两行，用时 Δt，则 v·Δt = C (1/(r1−y_h) − 1/(r2−y_h))。
- **相机高度 h**：同一行上车道宽 W 对应像素 Δx，则 h = W (y − y_h) / Δx。W 取 3.5–3.75 m 均匀分布。
- **前车距离**：Z = f · W_车 / w_px，f = C / h。货车货厢外宽 2.50 ± 0.05 m。
- **与尺度无关的量**：车头时距 Z / v 中 P 约掉了，不受标线规格影响——优先作为结论。

误差来源：标线施划误差与弯道/纵坡（周期 ±5%）、地平线、帧时刻、车道宽、前车宽度、边沿检测（±1 px）。

## 固定机位（监控）

`crashlab/geometry.py:calibrate_from_ground`：≥4 个已知地面点（虚线端点、停止线角点、灯杆根部，
在卫星图上量世界坐标）→ 单应 → 闭式求焦距 → 位姿 → 重投影误差最小化。车辆的接地点用“车身下沿离地高度”
平面反投影（高度本身带不确定度）。

## 物理换算（`crashlab/dashcam.py`, `crashlab/physics.py`）

- 停车距离 = v·t_反应 + v² / (2 μ g)，t_反应 0.8–1.5 s，湿滑沥青 μ 0.4–0.6。
- 一维碰撞 Δv、耗散能量：`collision_delta_v`、`absorbed_energy`。
- 多车链式追尾仿真：`simulate_chain`（分段刚度塑性压溃模型），用于交叉验证，不用于“演”画面里没有的结果。

## 不要做的事

- 用容器帧率直接算速度。
- 把单一规格假设下的速度当结论。
- 用三维动画补全画面中断之后的事。
